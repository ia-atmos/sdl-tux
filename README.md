# sdl-tux

A port of a slice of [SuperTux][1] (the tag `v0.7.0`) to [Atmos][2], over
the shared SDL environment ([env-sdl][3]).

The plan is in `.claude/plans/261113-sdl-tux.md`, and what is pending in
`.claude/plans/TODO.md`.
